A quick follow up to 0.4.0, mostly for Linux and Steam Deck players.

## Downloads
| OS | File |
|---|---|
| macOS (Apple Silicon) | `Theseus-v0.4.1-macos-app.zip` (the app), or `Theseus-v0.4.1-macos.zip` (bare binary, needs Homebrew libs) |
| Windows x64 | `Theseus-v0.4.1-windows-x64.zip`. Unzip anywhere, run `theseus.exe` |
| Linux x64 | `UIX-Desktop-v0.4.1-x86_64.AppImage` (Steam Deck too), or the tarball |
| Linux ARM64 | `UIX-Desktop-v0.4.1-aarch64.AppImage`, or the tarball |

`SHA256SUMS.txt` lists a checksum for every file.

## Fixed
- **The Linux AppImage didn't start on SteamOS or newer Debian.** 0.4.0 was built against a newer system library than those ship. Linux builds now target SteamOS 3.5 and newer, and every release checks for it.
- **The OpenGL renderer showed a black screen and closed** on some GPUs and drivers (#76).
- **Borderless and resized windows stretched the dashboard** until you resized it (#41, and the rest of #47).
- **Games in folders with spaces or (x86) didn't launch** on Windows, and .exe games now start directly (#38).
- **xemu ISOs with long paths didn't launch**, and Flatpak or snap xemu is found on its own (#84).
- **Big Steam libraries** now import completely, with icons fetched in the background (#28).
- **Folders showed up as movies** (#40). A folder counts as a movie when the video is right in it; collection folders like Action/Die Hard still work.
- Deleting a title no longer flattens grouped titles, and startup flags like `--dashboard` no longer change your saved startup choice.

## New: the guide
Press the Guide button, LT+B or F7 anywhere for a controller friendly guide: settings, accounts (Plex, Jellyfin, Xbox), adding games, logs and help, all without the old tool windows. It has its own on screen keyboard for paths and keys. Dashboard Green by default, with blue and red under Settings > Display > Guide Color. The old menu bar now only shows in development mode.

On first launch after updating you'll see a short Welcome screen once.
