Another testing build. The big one is Console Mode, for running UIX Desktop as the thing your machine boots into. Plex should actually connect now too. Kick the tires, especially on Windows, Linux and the Steam Deck.

## Downloads
| OS | File |
|---|---|
| macOS (Apple Silicon) | `Theseus-v0.4.3-testing-macos-app.zip` (the app), or `Theseus-v0.4.3-testing-macos.zip` (bare binary, needs Homebrew libs) |
| Windows x64 | `Theseus-v0.4.3-testing-windows-x64.zip`. Unzip anywhere, run `theseus.exe` |
| Linux x64 | `UIX-Desktop-v0.4.3-testing-x86_64.AppImage` (Steam Deck too), or the tarball |
| Linux ARM64 | `UIX-Desktop-v0.4.3-testing-aarch64.AppImage`, or the tarball |

`SHA256SUMS.txt` lists a checksum for every file.

## Console Mode
- Turn it on in Settings or start with `--console`: fullscreen, no window frame, the pointer stays hidden until the mouse moves, and it goes straight into the dashboard.
- **Start at Login** launches it in Console Mode when you sign in (LaunchAgent on macOS, autostart on Linux, the Run key on Windows).
- The guide's Exit page gets Go to Desktop, Sleep, Restart and Shut Down.
- A watchdog brings it back after a crash, and gives up if it crashes twice in a minute.
- The guide shows your battery, and Desktop Tools has a System Settings row.

## Plex and Jellyfin
- **Plex servers that never connected now do.** It tries every address plex.tv knows about instead of just one, and servers shared with you get the right sign-in, so no more empty library lists.
- Backing out of Plex or Jellyfin lands on the Media list again, and the Media button keeps working after.
- Videos go back to the dashboard when they finish, and playlists move on to the next item.

## Media and music
- The local movie and TV library rescans on its own, sorts properly, and turns names like `The.Matrix.1999.1080p` into The Matrix (1999).
- Music finds albums inside artist folders, and song tags and lengths read for every song, not just the first.

## Everything else
- The guide's settings pages are grouped with a line of help on every setting, and prompts say what A does instead of Select.
- The Settings window shows every setting again, newer ones included.
- Steam icons import properly in the AppImage.
- Uses much less CPU when it's minimized or hidden.
- `theseus.log` is tidier and opens with the version and OS.
- The terminal keeps printing after a restart from the guide.

Console Mode's power options, Start at Login and the crash watchdog have only been tried on macOS so far. If something's off, the issue form on GitHub plus `theseus.log` (Guide > Logs & Help > Copy Log) is the fastest way to get it fixed.
